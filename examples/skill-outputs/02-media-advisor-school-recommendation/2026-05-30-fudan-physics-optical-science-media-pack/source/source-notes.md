# Source Notes

## 官方一级方向

复旦大学物理学系“科学研究”页列出 6 个一级方向：

- 理论与计算物理
- 粒子物理、核物理
- 凝聚态物理
- 软物质与生物物理
- 光物理与光科学
- 天文与天体物理

本包选择“光物理与光科学”作为第一篇样例，因为方向边界清楚、关键词对学生友好、适合自媒体拆解。

## 光物理与光科学官方条目

方向页列出 17 位教师/条目：

- 安正华：微纳加工、纳米光电/光子学、低维半导体量子结构
- 丁鲲：非厄米物理、等离子体激元、卡西米尔相关效应
- 何琼：电磁特异介质、纳米光子学、电磁波调控
- 孔庆昌：非线性光学、激光物理、超快光学
- 林志方：光学微操控、人工电磁特异材料、光子晶体
- 刘韡韬：非线性光学和凝聚态物理实验、表面/界面非线性光学
- 刘晓晗：凝聚态光学性质、光子晶体
- 沈元壤：凝聚态/分子物理、非线性光学、激光光谱、表面科学
- 石磊：微纳光子学结构设计、制备、模拟、表征与应用
- 陶镇生：高次谐波、强场光学、光与物质相互作用
- 田传山：非线性激光光谱、材料表征、界面物理
- 吴赛骏：实验原子/光学物理、激光冷却、超冷原子、原子干涉、精密测量
- 吴施伟：扫描探针、超快纳米光学、小尺度体系物理
- 晏湖根：低维材料光谱、纳米光学、等离激元、太赫兹/远红外光谱
- 赵利：超快激光与物质相互作用、黑硅、微结构金属膜
- 周磊：超构材料、超表面、纳米光子学、等离激元
- 资剑：光子晶体、表面等离子激元、超构材料、结构色、水波周期结构

## 编辑拆分

为了自媒体读者理解，建议拆成 5 个子方向桶：

1. 微纳光子学 / 超构材料 / 光子晶体
2. 非线性光学 / 超快光学 / 强场光学
3. 量子光学 / 原子光学 / 精密测量
4. 低维材料光谱 / 太赫兹 / 等离激元
5. 表面界面光学 / 凝聚态光学

这是编辑分类，不是复旦官方分类。发布时要明确说明。
